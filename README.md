# GYN0-webapp

## GYNO MVP

Este repo contiened el codebase para una plataforma de training construida para vender y entregar un programa de calidad premium creado por el influencer fitness **Rodrigo Takano**.  
El proyecto esta siendo desarrollado con intenciones comerciales y esta planeado para evolucionar de una web MVP a una web + producto movil.


---

## 📌 Resumen del Proyecto

El objetivo de este proyecto es proveer:

- Un sitio web de marketing de alta calidad para un programa de fitness  
- Una plataforma de pago segura con procesamiento de transacciones  
- Un portal de contenido exclusivo para los clientes que adquieren el programa  
- Una base escalable para futuras funcionalidades (aplicación móvil, chatbot, análisis de datos, etc.)

El MVP se centra en la venta y la impartición de un único programa de formación con una experiencia de usuario sencilla y una infraestructura de backend fiable.
